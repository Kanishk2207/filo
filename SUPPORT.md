# Support

## Where to Ask for Help

- Usage questions: open an issue and label it as a question.
- Bug reports: use the bug issue template.
- Feature ideas: use the feature request template.
- Security issues: follow [`SECURITY.md`](SECURITY.md) and report privately.

## What to Include

Please include:

- Your OS and shell
- `filo --version`
- The command you ran
- Expected behavior vs actual behavior

This helps maintainers and contributors troubleshoot quickly.
